Power BI – Introduction Notes

1.What is Power BI?
Power BI is a Business Intelligence (BI) tool developed by
Microsoft.

It is used to:

1.Analyze data
2.Create reports
3.Build interactive dashboards
4.Share insights
5.It converts raw data into meaningful visual information.

2.Why Power BI is Used?
Organizations use Power BI to:

1.Track sales performance
2.Monitor business growth
3.Analyze customer behavior
4.Make data-driven decisions
5.Instead of reading thousands of rows of data, users can see results in charts and dashboards.


3.Components of Power BI
1.Power BI Desktop
Used to create reports
Install on computer
Free to use

2.Power BI Service
Cloud version
Used to share reports online

3.Power BI Mobile
View dashboards on mobile devices

4.Power BI Workflow
1.Get Data

5.Publish & Share

7️⃣ What is Power Query?

Power Query is used for data cleaning and transformation.

It helps to:

Remove duplicates

Change data types

Filter rows

Split or merge columns

Handle missing values

This step is done before creating reports.

8️⃣ What is Data Modeling?

Data modeling means:

Creating relationships between tables

Connecting primary key and foreign key

Managing multiple datasets

Example:
Customer Table ↔ Sales Table

9.What is DAX?
DAX (Data Analysis Expressions) is a formula language used in Power BI.
Used for:

1.Calculations
2.Aggregations
3.Creating measures
